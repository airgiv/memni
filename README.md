# memni — видео-мемы с вами и друзьями (тестовая версия)

Каталог мемов и короткий визуальный конструктор. Пользователь выбирает мем, по очереди заменяет участников своими фото и выбирает: посмотреть общее превью или сразу сделать видео. В готовом видео звучит **оригинальная дорожка** мема.

Стек: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, [@rapui/react](https://rapui.dev). Для реального режима — Supabase (Postgres, Auth, приватное Storage). Фоновый обработчик на Node использует FFmpeg. Интерфейс только в тёмной теме.

> **Сейчас работает демонстрационный режим.** Ключей моделей и Supabase нет, поэтому вместо генераций показываются помеченные примеры. Оплата тестовая: деньги не списываются.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000 — сайт и фоновый обработчик вместе
```

Production:

```bash
npm run build && npm start   # сайт
npm run worker               # фоновый обработчик — отдельный процесс
```

Проверки:

```bash
npm run typecheck
npm test                                    # модульные тесты
BASE_URL=http://localhost:3000 npm run e2e  # сквозной сценарий по HTTP (нужны сайт и обработчик)
npm run media:demo                          # пересоздать демо-материалы и вырезки участников
```

Нужен Node.js 22.13 или новее.

## Сценарий

| Экран | Что на нём |
|---|---|
| Каталог `/` | Плитка мемов: картинка и название. Поиск сверху на десктопе, кнопкой внизу на телефоне. Две колонки на телефоне |
| Мем `/m/[id]` | Название, крупный пример со звуком по нажатию, цена видео, кнопка «Сделать с собой» |
| Участник `?s=1…N` | Вырезка этого человека из исходного ролика, «Заменим этого человека», «1 из 2», «Добавь 1–3 фото. Лучше три», миниатюры (удалить или заменить), лента «Мои люди», «Не сохранять», теги образа после первого фото, «Дальше» |
| Выбор `?s=go` | «Посмотреть превью» (бесплатно или цена) или «Сразу видео» (цена) |
| Превью `?s=preview` | Крупное общее изображение, «Создать видео · 99 ₽», «Ещё вариант · 49 ₽», прежние варианты, «Изменить участников» |
| Заказ `/orders/[id]` | Короткий статус без процентов, затем видео со звуком, «Скачать», «Сделать ещё» |

- Черновик хранится на сервере, а шаг — в URL. Кнопка «Назад» и перезагрузка сохраняют фото, настройки и варианты.
- Если открыть мем снова, продолжится незаконченный черновик.
- На шагах участников ничего не генерируется: там только собираются фото и настройки.

## Деньги и повторы

Всё задаётся на сервере (`.env`):

| Параметр | По умолчанию |
|---|---|
| `FREE_PREVIEWS_PER_USER` | `1` — первое общее превью бесплатно (на пользователя, а не на черновик) |
| `PREVIEW_PRICE_MINOR` | `4900` — 49 ₽, пример цены |
| `VIDEO_PRICE_MINOR` | пусто → цена из шаблона (Hotel Lobby: 99 ₽, пример) |

- Платное действие выполняется, только если клиент прислал ровно ту сумму, которую показал пользователю. Иначе сервер отвечает 402 и возвращает актуальную цену. Перед каждой оплатой открывается окно с ценой.
- Возврат назад, перезагрузка или правка черновика не дают нового бесплатного превью.
- Двойной клик или вторая вкладка:
  - превью — возвращается уже запущенный запрос или покупка с тем же ключом;
  - видео — ключ идемпотентности строится из зафиксированных входных данных, поэтому это одно и то же задание и одна покупка.
- Переключение между готовыми вариантами бесплатно.
- Технический сбой:
  - неудачное превью возвращает бесплатное право или оплату;
  - неудачное видео можно повторить без оплаты в пределах бюджета попыток;
  - когда попытки кончаются, оплата возвращается. Автоматических перегенераций нет.
- Смена фото или образа не удаляет превью: они остаются в истории с пометкой «для прежних фото». Для видео используется только актуальное превью.

Платежи не подключены. Все покупки — тестовые (`purchases.status = test_paid | refunded`), и интерфейс это прямо говорит.

## Два пути к видео

- **С превью.** Выбранное актуальное общее изображение, фото участников, роли и образы.
- **Сразу видео.** Фото участников, роли, образы и исходный ролик. Скрытой платной картинки нет.

Пропускать ли превью, решает возможность провайдера (`planVideoInputs`):

| Провайдер | Без превью |
|---|---|
| Демо | поддерживается |
| Genjutsu (Higgsfield) | поддерживается: принимает до 8 изображений |
| Kling Motion Control | только мемы на одного человека: API принимает одно изображение персонажа. Для Hotel Lobby кнопка «Сразу видео» будет недоступна с короткой причиной; обходного пути нет |

Перед запуском фиксируются входные данные (копии файлов в папку задания), промпт, версия шаблона и цена.

## Оригинальный звук

- Аудио хранится в шаблоне с точными границами.
- Обработчик накладывает его через FFmpeg и проверяет результат через ffprobe: звук есть, длительность совпадает. Картинка при этом перекодируется, чтобы обрезка была точной.
- Песню никогда не ускоряем и не замедляем. Большое расхождение длительности → статус «проверяем вручную».
- Из готового ролика сохраняется кадр-постер.

## Шаблоны

Шаблоны описаны в `src/lib/templates/index.ts`. У каждой роли есть стабильный id, область на кадре и **вырезка из исходного видео** (`cutout: { src, atSec }`). Вырезки готовятся один раз скриптом `scripts/make-demo-media.ts` по моменту `atSec`, когда участник хорошо виден, и при открытии заказа заново не распознаются.

Образы тоже задаются в шаблоне: одежда из ролика, одежда с фото и варианты шаблона. Для Hotel Lobby это «Костюм» и «Халат».

**Все медиа — демонстрационные**, их нарисовал скрипт. Чужие ролики не скачивались. Как подключить реальный шаблон:

1. Положите лицензированные файлы в `public/templates/<id>/`.
2. Разметьте роли и подберите `atSec` для вырезок.
3. Выполните `npm run media:demo -- --cutouts`.
4. Поставьте `demoMaterials: false`, увеличьте `version`, выполните `npm run seed:templates`.

## rapui

- `@rapui/react@0.1.0` вышел без `"use client"`, поэтому `src/ui/rapui.ts` служит клиентской границей с явными реэкспортами.
- Стили подключены двумя слоями: предкомпилированный `styles.css` (в нём ключевые кадры компонентов) и `theme.css` для собственных утилит.
- **Кнопки.** Обёртка `src/ui/Button.tsx` передаёт штатный проп `roll={false}`: буквы при наведении больше не прокручиваются. `magnetic` выключен по умолчанию, поэтому кнопка не двигается и не меняет размер. Заливка фона при наведении осталась и перекрашена под тёмную палитру в `globals.css`. Фокус, загрузка и disabled — библиотечные. Для кнопок внутри компонентов rapui (например, AlertDialog) в CSS есть страховка от прокрутки букв.
- **Тёмная тема.** `data-rap-theme="dark"` задаётся на сервере, поэтому светлой вспышки нет. Токены подстроены в `globals.css`. Уведомления перекрашены: в тёмной теме rapui они были светлыми плашками.
- **Локальные обёртки** вместо правки библиотеки:
  - `VideoPlayer` — рассинхронизация при гидрации из-за кнопки PiP;
  - `Switch` — русские подписи.

## Supabase (реальный режим)

1. Примените `supabase/migrations/0001_init.sql` и `0002_single_preview_and_purchases.sql`.
2. Включите Anonymous sign-ins.
3. Выполните `npm run seed:templates`.
4. Заполните `.env.local` по `.env.example`.

## Telegram

Общий конструктор. Тема всегда тёмная; безопасные отступы и кнопка «Назад» работают внутри Telegram. Сервер проверяет initData через HMAC. Без токена бота вход не работает, с настоящим ботом не проверялся.
